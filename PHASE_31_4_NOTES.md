# Phase 31.4 - Gameplay Feedback Polish

Fast Fingers: six short gold/cyan sparks radiate from each successful target tap.
Memory Match: card flips get a gentle reveal bounce; successful pairs briefly pulse.
Number Merge: every successful merge emits a brief gold/cyan burst around the score.
All effects ignore touch, use built-in Godot tweens, and are automatically freed. No scoring, progression, navigation, or saved-data changes.
This is a targeted feedback pass, not a complete redraw of all 13 games. Test in Godot 4.7.2 and on iPhone Safari.
