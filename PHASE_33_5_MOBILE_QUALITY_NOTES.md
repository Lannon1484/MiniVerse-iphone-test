# Phase 33.5 - Mobile Gameplay Quality Pass

This is a focused usability pass on the three newest games, retaining the existing 16-game project and saved data.

- Bubble Burst: a full launch lane no longer immediately ends a round; blocked lanes are visibly disabled, and the player can select another legal lane. The ordinary game-over checks remain.
- Gem Blocks: board size is capped by screen height as well as width to protect the shape controls on short phones. Internal button arrays reset when a new game is started.
- Rune Runner: slightly more HUD top clearance, a shorter minimum arena for smaller screens, and taller left/right touch buttons.

Gameplay art, stars, rewards, menus, achievements and existing games remain intact. The ZIP passed integrity validation; Godot compilation and actual iPhone tests have not been performed.
