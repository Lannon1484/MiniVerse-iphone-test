# Phase 30.5 - Fantasy Gameplay Frames

Adds a compact illustrated game-specific fantasy banner above the active gameplay control in each of the 13 mini-games. Uses the existing illustrated card assets and gold-framed visual style. Gameplay controls, scoring, saves, progression, and menus are unchanged. The header is outside the game control so it does not intercept touches. Validate screen fit and scrolling on iPhone Safari and Godot 4.7.2.
