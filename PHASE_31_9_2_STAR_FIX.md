# Phase 31.9.2 - Number Merge Three-Star Fix

Number Merge automatically completes when its level score target is reached. The shared 3-star rule previously required 160% of the target, which was unreachable after automatic completion. Successful Number Merge level clears now award 3 stars. Other games keep their original star logic. Existing best stars, saves, achievements and progression are preserved.
